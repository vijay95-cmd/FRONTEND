## 📌 Project Overview

This project is a frontend practice implementation of an Amazon-style shopping website. It focuses on responsive page structure, e-commerce navigation, category sections, product cards, promotional content, search interaction, and a dynamic cart counter using vanilla web technologies.

## ✨ Features

- 🏠 Amazon-inspired navigation and homepage
- 🔍 Search bar with category selection
- 🗂️ Electronics, Fashion, Home & Kitchen, and Books categories
- 🛍️ Featured product cards with pricing and ratings
- 🛒 Add-to-cart interaction and cart counter
- 🎯 Deals and promotional sections
- 📱 Responsive layout
- 🎨 Inter-font based modern UI
- 📦 Delivery, payment, and returns information
- 📱 Mobile-friendly viewport configuration

## 🛠️ Tech Stack

| Technology | Purpose |
| --- | --- |
| HTML5 | Semantic page structure |
| CSS3 | Layout, styling, cards, responsive design |

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/vijay95-cmd/FRONTEND.git
```

2. Open the `amazon clone` folder.
3. Open `index.html` in a browser or use VS Code Live Server.
